# Публикация для доступа с телефона

GitHub хранит код, но не запускает Flask-приложения. Для публичного сайта
используйте Render: он создаст HTTPS-адрес вида `https://phishing-detector.onrender.com`.

1. Создайте пустой репозиторий на GitHub и загрузите туда все файлы проекта,
   кроме тех, что исключены `.gitignore`.
2. Войдите на https://render.com, выберите **New → Blueprint** и подключите
   этот GitHub-репозиторий. Render распознает `render.yaml`.
3. Нажмите Apply. После сборки откройте адрес `onrender.com` — он будет
   работать с телефона и компьютера по HTTPS.

## Важное ограничение базы данных

На бесплатном Render локальная SQLite-база очищается при перезапуске сервиса.
Это подходит только для демонстрации. Для постоянных учётных записей в Render
добавьте persistent disk (платный тариф) с точкой монтирования
`/opt/render/project/src/data` и переменную окружения:

`DATABASE_PATH=/opt/render/project/src/data/phishing_history.db`

Для полноценного многопользовательского сервиса лучше перенести базу на
управляемый PostgreSQL перед публичным запуском.
