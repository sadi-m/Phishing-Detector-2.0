Phishing Detector 2.0 это веб-приложение для анализа интернет-ссылок и выявления признаков фишинговых и потенциально опасных URL. Проект разработан на Python с использованием Flask и представляет собой развитие первоначальной версии системы обнаружения фишинговых ссылок.

Приложение работает как локальный веб-сервис по адресу http://127.0.0.1:8080 и предоставляет пользователю интерфейс для проверки URL. Система анализирует введённую ссылку, определяет подозрительные признаки и сохраняет результаты проверок в базе данных.

В версии 2.0 основной акцент был сделан не только на функциональности, но и на безопасности самого приложения. Были устранены потенциально опасные настройки и добавлены дополнительные механизмы защиты веб-приложения.

В версии Phishing Detector 2.0 особое внимание было уделено не только функциональности, но и безопасности самого веб-приложения. В процессе модернизации были устранены потенциально опасные элементы первоначальной реализации и добавлены дополнительные механизмы защиты.

Одним из основных изменений стало безопасное управление секретным ключом Flask. Ключ больше не хранится непосредственно в исходном коде: приложение самостоятельно создаёт уникальный секретный ключ при первом запуске и сохраняет его локально. Также были удалены зашитые в программный код учётные данные администратора.

Для повышения безопасности отключён режим отладки Flask, который может раскрывать внутреннюю информацию приложения. Реализована защита от CSRF-атак, предотвращающая выполнение важных действий через поддельные запросы с чужих сайтов. Административные операции, изменяющие данные, переведены с GET-запросов на защищённые POST-формы.

Дополнительно были настроены защитные HTTP-заголовки, безопасные параметры cookie и автоматическое завершение пользовательской сессии через восемь часов. Для регистрации, авторизации и проверки URL установлено ограничение количества запросов, что позволяет снизить риск перебора паролей и автоматизированного спама.

Также была усилена проверка пользовательских данных: имени пользователя, пароля, отзывов и длины URL. Убран автоматический запрос геолокации при регистрации, что повышает уровень конфиденциальности пользователей.

Отдельное внимание уделено экспорту данных в Excel. Реализована защита от вредоносных формул, которые могут представлять опасность при открытии экспортированного файла.

Для безопасной работы с системой контроля версий добавлен .gitignore, предотвращающий публикацию базы данных и секретных файлов. Кроме того, созданы SECURITY.md с рекомендациями по безопасному развёртыванию и .env.example с примером конфигурации.

Таким образом, Phishing Detector 2.0 представляет собой развитие первоначального прототипа в более защищённое веб-приложение, сочетающее анализ фишинговых URL, систему пользователей, административное управление, хранение истории и комплекс современных механизмов защиты веб-приложений.
