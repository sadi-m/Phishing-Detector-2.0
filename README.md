Phishing Detector 2.0 — это веб-приложение для анализа интернет-ссылок и выявления признаков фишинговых и потенциально опасных URL. Проект разработан на Python с использованием Flask и представляет собой развитие первоначальной версии системы обнаружения фишинговых ссылок.

Приложение работает как локальный веб-сервис по адресу http://127.0.0.1:8080 и предоставляет пользователю интерфейс для проверки URL. Система анализирует введённую ссылку, определяет подозрительные признаки и сохраняет результаты проверок в базе данных.

В версии 2.0 основной акцент был сделан не только на функциональности, но и на безопасности самого приложения. Были устранены потенциально опасные настройки и добавлены дополнительные механизмы защиты веб-приложения.
